"Look up owner" opens up to three real, live sources: an OpenCorporates search pre-filled with the business name and jurisdiction (OpenCorporates aggregates official state filings), the official state-by-state Secretary of State registry directory so you can go straight to that state's own .gov database, and a plain Google search as a fallback. Officer/owner disclosure varies a lot by state — some states publish officer names for free, others (like California) only show entity-level and registered-agent data. Always treat what you find as a starting point to confirm, not a guaranteed current owner, since annual-report cycles mean state records can lag real ownership changes by up to a year.
